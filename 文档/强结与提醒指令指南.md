# 强结与提醒指令指南

管理员日常处理"催更/清场"时会用到的一组指令。这几个指令容易混，本文只讲怎么选、怎么用，不重复讲实现细节。

## 一、指令总览

| 指令 | 范围 | 判定口径 | 动作 |
|---|---|---|---|
| `提醒超时` | 单群 / 全部 | 系统统一超时阈值（`设置 互动参数`→超时时间，默认180分钟） | 通知（双向不同话术） |
| `查看到期群 提醒` | 全部到期群 | 小群过期时间（`设置 互动参数`→小群过期时间，默认48h） | 通知（单条） |
| `一键通知 N 弧长` | 全部符合条件的群 | 自定义小时数 N（未回复时长） | 通知（双向不同话术） |
| `一键通知 N 开群` | 全部符合条件的群 | 自定义小时数 N（开群时长） | 通知（单条） |
| `强结私约 [群号]` | 单群 | 无需判定，管理员直接指定 | 强制结束 |
| `一键强结 N 弧长` | 全部符合条件的群 | 自定义小时数 N（未回复时长） | 批量强制结束 |
| `一键强结 N 开群` | 全部符合条件的群 | 自定义小时数 N（开群时长） | 批量强制结束 |

## 二、两个核心概念：弧长 vs 开群

这是最容易搞混的地方，先分清楚：

- **弧长**：看"有没有人一直不回复"。只要群里**任意一个人**已经轮到自己该回复、却卡了超过 N 小时，这个群就算命中。哪怕群才开 2 小时，只要有人半小时不回、又过了 N 小时没理会，一样会被抓出来。
- **开群**：只看"这个群开了多久"，不管里面聊没聊、有没有卡顿。哪怕两人一直在你来我往地正常互动，只要群龄超过 N 小时，也会被抓出来（因为可能是玩家忘了结束私约）。

一句话：**弧长抓"卡壳的人"，开群抓"忘了结束的群"**。两者不互斥，可以分别跑。

## 三、日常推荐流程

1. **先通知，再强结。** 不要直接跑 `一键强结`，先用 `一键通知` 让当事人有机会自己处理（回复或手动「结束私约」）。给出合理的缓冲时间（比如通知用 12h 口径，强结用 24h 口径），避免误伤正在正常互动但恰好卡在阈值边缘的群。
2. **弧长优先于开群。** 弧长命中说明确实有人没回，处理紧迫性更高；开群命中不代表没人回复，可能只是玩家结束后忘记发「结束私约」，可以放宽一些时间再处理。
3. **单群例外单独处理。** 遇到玩家私聊说明情况（比如请假、临时有事）的群，用 `强结私约 群号` 单独处理即可，不用等批量指令扫到。

参考节奏（仅供参考，按自己群里的活跃度调整）：
```
一键通知 12 弧长      ← 12小时没回的先催一遍
一键通知 24 开群      ← 开了一天的群提醒一下是不是该收尾了
（等待玩家自行处理一段时间）
一键强结 24 弧长      ← 24小时还没回的直接强结
一键强结 48 开群      ← 开了两天还没结束的直接强结
```

## 四、强结是否发放奖励

`强结私约` 和 `一键强结` 共用同一个开关：

```
设置 互动参数
【强结发放奖励】关闭 / 开启
```

- **关闭（默认）**：强结不发结戏奖励，目标群会提示"不发放结戏奖励"。
- **开启**：强结按正常结戏规则发奖励（走和「结束私约」一样的奖励发放路径），目标群提示"已发放结戏奖励"。

复盘/存档流程（RP存档、字数统计等）跟这个开关无关，强结永远和正常结束一样正常存档，只是剧情中途被打断而已。

修改方式：
```
设置 互动参数
【强结发放奖励】开启
```
发送这两行即可切换（第一行是分类标识符，不能删）。

## 五、注意事项

- **弧长/开群命中的是同一批数据，但来源不同**：弧长基于 `group_timers`（谁在等谁回复），开群基于 `group_expire_info`（群什么时候开的）。一个群可能同时命中两种口径，也可能只命中一种，正常现象。
- **老群的"开群时长"可能有轻微偏差**：多数建群路径现在都会记录精确的开群时刻，但如果你的库里有本次改动之前创建、至今仍未结束的老群，系统会用"到期时间 − 当前的小群过期时间设置"反推开群时刻。如果这期间你调整过「小群过期时间」这个参数，老群的判定会有点偏差（新群不受影响）。
- **批量指令不会重复打扰**：`一键通知`/`一键强结` 每次调用都会重新扫描当前状态，不会因为之前通知过就跳过——如果玩家还是没处理，可以隔一段时间再跑一次同样的指令。
- **微信群不走这两个批量口径**：微信群的开群/超时判定走独立的存储（`wechat_groups`），`一键通知`/`一键强结` 目前只扫描 QQ 群号池里的群。微信群需要用 `强结私约 群号` 单独处理。
