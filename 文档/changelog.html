1.4.0 最新
管理员强结指令 · 官约调整 Latest
新增强结私约指令；官约指令改名并调整回执格式
  • New 新增 强结私约 指令（管理员专用）：强制结束当前群，跳过复盘检查，执行完整清理流程（释放群号、更新日程状态、重置计数、清除计时器），但不发放任何结戏加成奖励与抽取机会
  • Update 结戏后向群内明确提示「管理员强结不发放任何结戏奖励」，避免玩家等待奖励产生困惑
  • Fix 官约相关指令改名，与现有指令体系保持一致
  • Fix 更改官约回执格式，信息展示更清晰
1.3.9 最新
本场统计扩展 · 礼物混乱投递 Latest
短信/礼物/约会/心愿双向互动 Top3；礼物新增丢失与送错概率
  • 本场统计
  • New 本场统计 新增互动 Top3 模块：展示最喜欢给你发短信 / 你最喜欢发短信给的前三角色（仅计发送成功次数）
  • New 礼物同样记录双向计数：最喜欢送你礼物 / 你最喜欢送礼给的 Top3
  • New 私约与电话合并计数：最喜欢约你 / 你最喜欢约的 Top3（支持多人约批量记录）
  • New 心愿摘取双向计数：摘心愿 成功建群后记录；展示最喜欢摘你心愿 / 你最喜欢摘谁的心愿前三角色
  • 礼物系统
  • New 新增「送礼混乱丢失」概率（%）：礼物概率丢失，双方均显示正常（发件人看到成功提示，收件人无任何消息）；丢失时仅记发件人 sent 计数，不记收件人 received，不触发公开广播
  • New 新增「送礼混乱送错」概率（%）：礼物概率被送至随机其他角色，发件人提示仍显示原收件人（不知情）；图鉴与互动计数记录实际收件人
1.3.8 官约重构
心愿隐私优化 · 便捷官约重构
心愿匿名署名、同步名片指定群类型、binary tag 分组系统
  • 心愿系统
  • Update 看心愿 及公共频道推送不再显示发布者真实角色名，改为仅显示性别 emoji（👨 / 👩）
  • New 挂心愿 支持末尾追加 | 昵称 自定义显示名（最多10字）。格式：挂心愿 时间 地点 内容 | 昵称
  • New 悬赏心愿 支持第二个 | 追加自定义昵称（最多10字）。格式：悬赏心愿 时间 地点 内容 | 物品名 数量 | 昵称
  • 同步名片
  • Update 同步名片 改为必须指定目标群类型：同步名片 公告 / 同步名片 戏群 / 同步名片 水群，每次仅同步到指定群
  • 便捷官约
  • New 新增 修改tag 指令：管理员可创建自定义 binary tag（如贵族/平民），将角色分配到各分类，随时覆盖更新
  • Update 计划官约 第一参数从「是/否」改为 tag 名字或「无」：填 tag 名按各分类交替分桶，填「无」则纯随机分组；未被 tag 覆盖的玩家随机补入
1.3.7 拍卖强化
拍卖系统强化 & 账号存储修复
拍卖系统新增失效机制与手动结算；修复多处管理员指令的账号 key 不一致问题
  • 拍卖系统
  • Fix 修复 设置 拍卖设置 批量回填时，拍卖货币值含括号提示文字导致匹配失败的问题

1.3.6 最新
便捷官约系统
新增计划官约与执行官约两条指令，实现一键批量发起官约
  • New 新增 计划官约 指令：输入是否需要异性、组数、天数、时间段、地点列表，自动将所有非 NPC 玩家分组并分配地点，生成官约方案
  • New 新增 执行官约 指令：一键执行已保存的官约方案，同时发起所有分组官约（分配群号、更新日程、向各玩家私群推送、启动计时器）
  • New 异性搭配模式：填写「是」时按性别交替分桶，尽量保证同组内男女混搭
  • Update 地点数量与组数不一致时提前拦截，提示「建设不成功」；任何玩家有时间冲突（锁定或已有安排）时同样拦截
  • Update 执行前二次校验时间冲突，防止方案保存后因其他约会占用而出现错误；执行完毕后自动清空方案存储
  • Docs changriGuide 与 managementGuide 同步新增便捷官约说明、指令条目及流程代码块
