# 角色投递系统 · 安装指南

本系统基于 Python Flask，适用于 **Windows Server（64位）** 服务器。
安装完成后，投递表单对外公开，管理后台需登录访问。

---

## 一、压缩包内容

```
角色投递系统/
├── 安装指南.md          ← 本文件
├── 招募系统/            ← 网站主程序
│   ├── app.py
│   ├── requirements.txt
│   └── templates/
├── wheels/              ← Python 依赖包（离线安装用）
└── nssm.exe             ← 服务管理工具（开机自启用）
```

---

## 二、前置要求

| 项目 | 要求 |
|------|------|
| 服务器系统 | Windows Server（64位） |
| 服务器网络 | 需开放 **5000 端口**（TCP 入方向） |
| 本地操作系统 | Mac 或 Windows 均可 |
| Python | 需在服务器上安装 Python 3.11（64位） |

> 阿里云安全组需添加入方向规则：协议 TCP，端口 5000，来源 0.0.0.0/0。

---

## 三、安装步骤

### 第一步：在服务器上安装 Python 3.11

SSH 或 RDP 连接到服务器后，下载并安装 Python：

```cmd
curl -o python-installer.exe https://mirrors.tuna.tsinghua.edu.cn/python/3.11.9/python-3.11.9-amd64.exe
```

下载完成后，**双击运行安装包**（RDP 连接后在图形界面操作）：
- 勾选 **Add Python to PATH**
- 点击 **Install Now**
- 安装完成后点击 **Disable path length limit**，再关闭

安装完成后记下 python.exe 的路径，通常为：
```
C:\Users\Administrator\AppData\Local\Programs\Python\Python311\python.exe
```

验证安装：
```powershell
& "C:\Users\Administrator\AppData\Local\Programs\Python\Python311\python.exe" --version
# 应显示：Python 3.11.9
```

---

### 第二步：上传文件到服务器

**从 Mac 上传**（在本地 Terminal 执行）：
```bash
scp -r 角色投递系统/招募系统 Administrator@你的服务器IP:C:/招募系统
scp -r 角色投递系统/wheels Administrator@你的服务器IP:C:/wheels
scp 角色投递系统/nssm.exe Administrator@你的服务器IP:C:/Windows/System32/
```

**从 Windows 上传**（在本地 PowerShell 执行）：
```powershell
scp -r 角色投递系统\招募系统 Administrator@你的服务器IP:C:/招募系统
scp -r 角色投递系统\wheels Administrator@你的服务器IP:C:/wheels
scp 角色投递系统\nssm.exe Administrator@你的服务器IP:C:/Windows/System32/
```

---

### 第三步：安装 Python 依赖

在**服务器的 PowerShell** 中执行（一行命令）：

```powershell
& "C:\Users\Administrator\AppData\Local\Programs\Python\Python311\python.exe" -m pip install C:\wheels\markupsafe-3.0.3-cp311-cp311-win_amd64.whl C:\wheels\blinker-1.9.0-py3-none-any.whl C:\wheels\click-8.3.3-py3-none-any.whl C:\wheels\colorama-0.4.6-py2.py3-none-any.whl C:\wheels\itsdangerous-2.2.0-py3-none-any.whl C:\wheels\zipp-3.23.1-py3-none-any.whl C:\wheels\importlib_metadata-9.0.0-py3-none-any.whl C:\wheels\jinja2-3.1.6-py3-none-any.whl C:\wheels\werkzeug-3.1.8-py3-none-any.whl C:\wheels\flask-3.1.3-py3-none-any.whl --no-index
```

出现 `Successfully installed flask...` 即为成功。

---

### 第四步：设置开机自动运行

在**服务器的 PowerShell** 中执行：

```powershell
nssm install FlaskApp "C:\Users\Administrator\AppData\Local\Programs\Python\Python311\python.exe"
nssm set FlaskApp AppParameters "C:\招募系统\app.py"
nssm set FlaskApp AppDirectory "C:\招募系统"
nssm set FlaskApp Start SERVICE_AUTO_START
nssm start FlaskApp
```

服务启动后，网站即可访问。关闭 RDP 或重启服务器均不影响运行。

**常用服务管理命令：**
```powershell
nssm stop FlaskApp     # 停止服务
nssm start FlaskApp    # 启动服务
nssm restart FlaskApp  # 重启服务（更新文件后使用）
```

## 六、管理后台功能

- **⚙ 字段管理**：自定义投递表单字段（QQ号、在线时间、弧长为固定字段，不可删除）
- **🔑 修改密码**：修改管理员登录密码
- **🗑 清空投递**：清空全部或指定天数前的投递记录
- **标记功能**：对每条投递标记「⭐ 意向录取」「? 待定」「✕ Pass」
- **内部备注**：对每条投递添加仅自己可见的备注，自动保存

## 七、常见问题

**Q：上传文件后网站没有更新？**
> 需要重启服务：`nssm restart FlaskApp`

**Q：访问 5000 端口无法打开？**
> 检查阿里云安全组是否添加了 TCP 5000 入方向规则，以及 Windows 防火墙是否放行。

**Q：忘记管理员密码？**
> 用文本编辑器打开服务器上的 `C:\招募系统\data\config.json`，删除其中的 `"password_hash"` 那一行，重启服务后密码恢复为初始密码 `marcusra9`。
