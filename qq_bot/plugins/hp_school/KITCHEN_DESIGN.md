# 厨房养成系统设计文档

## 系统概述

类似魔药系统的独立日常养成模块。玩家在每天课程之外，可以在霍格沃茨厨房制作食物。通过收集配方、烹饪食物、积累经验，逐步成为"美食大师"。系统共包含 **120+ 魔法食物配方**。

---

## 1. 核心机制

### 1.1 制作流程
- **配方选择** → **材料消耗** → **3 步骤选择制作** → **成功/失败** → **获得食物**
- 失败时浪费材料但获得少量经验（鼓励尝试）
- 成功时获得"料理"物品 + 经验

### 1.2 每日活动限制
- **厨房活力** 上限 40 点，每 25 分钟恢复 8 点（类似体力系统）
- 制作一次需消耗 8 点活力（即每天最多 5 次，可缓解活力不足）
- 使用配方可以获得 50% 概率回复少量活力（烹饪太多会疲劳）

### 1.3 经验与等级
- 烹饪经验独立计数（类似各科目等级）
- 烹饪等级 1-7 级，每级解锁新配方
- 更高等级的配方成功率更高，获得经验更多

## 2. 配方系统（120 个配方）

### 2.1 配方结构
```python
{
    "key": "scrambled_eggs",
    "name": "炒鸡蛋",
    "grade": 1,  # 解锁年级/烹饪等级
    "exp": 8,    # 成功获得经验
    "ingredients": {
        "mat_egg": 2,
        "mat_butter": 1,
        "mat_salt": 1
    },
    "effect": "恢复 5 点厨房活力；提升下次课堂表现 +1",
    "steps": [
        {
            "desc": "鸡蛋打入碗中，黄白分离还是混在一起？",
            "options": ["保留蛋液", "打散混合", "只要蛋白"],
            "correct": 1  # 下标
        },
        {
            "desc": "黄油在平底锅里融化，冒起细微白烟。",
            "options": ["立刻倒入蛋液", "等黄油变棕色再倒", "关火再加鸡蛋"],
            "correct": 0
        },
        {
            "desc": "鸡蛋逐渐凝固，但还有液体流动的迹象。",
            "options": ["继续大火炒至完全干身", "中火轻轻推动，保留奶油质感", "立刻盛出"],
            "correct": 1
        }
    ],
    "category": "breakfast",  # 分类：早餐/主食/甜点/汤/魔法餐等
}
```

### 2.2 配方分类（共 120+）
| 分类 | 数量 | 例子 | 效果方向 |
|------|------|------|--------|
| **早餐** | 15 | 炒鸡蛋、麦片粥、烤面包 | 恢复活力 |
| **主食** | 20 | 烤鸡、意面、汉堡 | 通用或特定学科加成 |
| **汤类** | 15 | 蔬菜汤、南瓜汤、骨汤 | 回血/清除负状态 |
| **甜点** | 20 | 巧克力蛋糕、饼干、冰淇淋 | 心情/幸福度 |
| **魔法美食** | 25 | 勇士汤、聪慧果酱、隐身茶 | 特殊 buff（比如隐身探险加成） |
| **饮品** | 15 | 热巧克力、南瓜汁、蜜酒 | 小幅长效 buff |
| **点心/小食** | 15 | 坚果、糖果、饼干 | 快速小补 |

### 2.3 解锁机制
- **初始解锁**：等级 1-2 可学 15 个基础配方（从菜单中选择学习）
- **经验解锁**：每升一级（烹饪经验达到门槛）自动解锁该等级的新配方
- **年级门槛**：部分高级配方要求达到特定年级（如 6 年级才能解锁高魔法美食）

## 3. 食物效果表

### 3.1 效果类型
| 效果类型 | 例子 | 持续时间 |
|---------|------|--------|
| **体力恢复** | +5-20 点活力 | 即时 |
| **课堂加成** | 下次课堂表现 +1-3 | 一次课程 |
| **经验加成** | 下次烹饪 +20% 经验 | 下一次烹饪 |
| **采集加成** | 下次禁林采集材料 +1 | 一次采集 |
| **心情值** | 增加小幸福度 | 短期 |
| **特殊状态** | 隐身、水下呼吸等 | 指定时长 |
| **学院杯加成** | 下次魁地奇表现 +2 | 一场比赛 |

## 4. 食柜系统（Inventory）

### 4.1 存储
- **食柜**：玩家烹饪的食物存放处
- 可存放 50 份食物（每种食物可多份）
- 食物不会过期，但可以分享、赠送或丢弃

### 4.2 食用/使用
- 玩家可以**主动食用**某种食物触发 buff
- 系统提示食物效果
- 食物消耗

### 4.3 web 后台
- 显示食柜内容（食物名 + 数量）
- 显示已学配方列表
- 显示烹饪等级进度

## 6. 数据库表

### 6.1 kitchen_recipes（配方库 - 只读）
```sql
CREATE TABLE kitchen_recipes (
    key TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    grade INTEGER NOT NULL,
    exp INTEGER NOT NULL,
    ingredients JSON NOT NULL,  -- {"mat_egg": 2, ...}
    effect TEXT NOT NULL,
    steps JSON NOT NULL,  -- 3-4 个步骤
    created_at INTEGER
);
```

### 6.2 kitchen_exp（烹饪经验）
```sql
CREATE TABLE kitchen_exp (
    uid TEXT PRIMARY KEY,
    exp INTEGER NOT NULL DEFAULT 0,
    level INTEGER NOT NULL DEFAULT 1,
    kitchen_stamina INTEGER NOT NULL DEFAULT 40,
    stamina_updated_at INTEGER NOT NULL DEFAULT 0
);
```

### 6.3 kitchen_learned_recipes（玩家已学配方）
```sql
CREATE TABLE kitchen_learned_recipes (
    uid TEXT NOT NULL,
    recipe_key TEXT NOT NULL,
    learned_at INTEGER NOT NULL,
    PRIMARY KEY (uid, recipe_key)
);
```

### 6.4 kitchen_inventory（食柜）
```sql
CREATE TABLE kitchen_inventory (
    uid TEXT NOT NULL,
    food_key TEXT NOT NULL,  -- 对应 recipe_key
    quantity INTEGER NOT NULL,
    created_at INTEGER NOT NULL,
    PRIMARY KEY (uid, food_key)
);
```

### 6.5 kitchen_log（制作历史）
```sql
CREATE TABLE kitchen_log (
    uid TEXT NOT NULL,
    recipe_key TEXT NOT NULL,
    day INTEGER NOT NULL,
    success BOOLEAN NOT NULL,
    exp_gained INTEGER NOT NULL,
    timestamp INTEGER NOT NULL
);
```

## 7. 实现步骤

### Phase 1（核心玩法）
1. 创建 `kitchen.py` 模块（配方数据 + 制作逻辑）

3. 数据库表设计
4. QQ 命令：`/制作 [配方名]`、`/食柜`、`/学配方`

   - 食柜展示

6. 优化烹饪过程的文案和交互

### Phase 3（扩展）
7. 每日签到赠送固定材料
8. 特殊事件（学年大餐、节日美食等）

## 8. 设计亮点

✨ **与现有系统融合**
- 食物 buff 直接助力课堂、禁林、魁地奇等玩法
- 材料来源可联动禁林采集、商店购买

✨ **每日循环**
- 上课 → 用活力制作食物 → 食用食物加强下次课程  
- 形成正反馈的日常习惯

✨ **长期收集**
- 120+ 配方足以花数月逐一解锁
- 成就系统鼓励"集大全"

✨ **低门槛高上限**
- 新手也能做简单食物
- 高手可以钻研稀有配方和完美制作

## 9. 问题与答案

**Q: 材料从哪来？**  
A: 初期给固定材料包，后续可通过禁林采集、商店购买、事件赠送获得。

**Q: 和魔药系统重复了吗？**  
A: 否。魔药是"战斗 buff"（禁林冒险），厨房是"日常养成"（课堂、活力恢复）。可以相互配合。

**Q: 做出来的食物能交易吗？**  
A: 第一版不支持。后期可考虑赠送给好友、参与学院活动等社交扩展。

**Q: 材料会消耗完吗？**  
A: 需要设计供应链。可考虑：
- 每周自动赠送材料包
- 禁林采集产生副产品（食材）
- 商店用金币购买高端材料
