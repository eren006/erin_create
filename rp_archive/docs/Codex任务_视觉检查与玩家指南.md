## 任务 3：玩家指南和 hub 手册补「探索踩点」

纯文字和排版。**不要新增指令**（探索踩点是网页玩法，没有群指令）。

### 要写清楚的内容（面向玩家，口吻参照所在文件里现有段落）
1. **怎么进**：用和小手机同一个角色激活码；打开 `archive.changri.work/x`（把激活码输进去），或让管理员发你 `archive.changri.work/x/你的激活码` 的直达链接。登录后这台设备 30 天内不用重输。管理员没开放时只会看到「探索还没有开放」。
2. **每天次数**：每人每天有固定次数，默认大家一样，管理员可以单独给某个人调多或调少；每天按北京时间自然日刷新（默认 0 点，管理员可改）。管理员还能发「临时次数」：先用完当天的日常次数才会开始用临时次数，临时次数不会过期。
3. **怎么踩点**：在地图上点一个地点（有背景图时点图上的标记，也可以点下面的列表）→ 点「踩点」，扣一次次数，随机翻出一样东西：线索、物品，或什么也没找到。
4. **线索板**：翻到的线索收进「线索板」。默认**按地点归纳**（每个地点一组，组内按找到的先后排，有没看过的新线索会标出来），也可以切换成「按时间」，还能搜索。**同一个地点的同一条线索只会拿到一次**；如果这个地点的线索已经全拿过，再踩会提示「这里没有新发现了」，**这种情况不扣次数**，可以换别处。
5. **物品自动入包**：翻到的物品必须是系统里注册过的物品，会自动加进你的背包，机器人大约半分钟内处理完；踩点后提示「入包中」，之后到「记录」页看结果：已入包 / 入包失败。
6. **入包失败怎么办**：「记录」里显示「入包失败」时，这次踩点已经扣了次数，**次数不会自动退回**，请联系管理员——管理员可以重新发放物品，或给你补临时次数。
7. **记录页**：列出最近的踩点，用到临时次数的会有标记。

### 写在哪里
- `长日系统/player_guide.html`：新增一个**独立的功能分区**（`<details class="feat-section" id="sec-探索踩点">`，结构、图标写法、目录条目都照抄同文件现有分区，比如 `sec-地点系统`；左侧「功能目录」里也要加对应条目，顶部搜索要能搜到）。分区里按上面 1~7 点写成若干条目，每条用文件里现有的 `cmd-desc` 一类的条目样式（没有指令就别写指令格式，用「怎么用」这类标题）。
- `长日系统/changri_hub.html`：在内嵌的手册指南区里（搜 `guide-web`，「🌐 存档网页端 · 功能速查」）补一小节「探索踩点」，写上面 1~6 点的**精简版**（每点一两句），样式照抄该区域现有小节。
- **不要**改 hub 里的版本号、`CHANGELOG`、`SUBSYSTEMS`，也不要碰 hub 新加的 `.webx` 区域；`player_guide.html` 没有版本号，不用管。
