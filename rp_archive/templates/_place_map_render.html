{# 地点示意图渲染器：后台编辑器和小手机「地图」页共用，只负责「数据 → SVG 字符串」。 数据格式（存在 site_config 的 place_maps 里，按地点名分开）： { w, h, visible, items: [ {t:'rect', x,y,w,h, kind:'room|building|plaza|road|green|water', name}, // 格子坐标，一格 = 一个单位 {t:'door', x,y, o:'h|v'}, // h=格子上边缘的横门，v=格子左边缘的竖门 {t:'mark', x,y, s, icon, label}, // 装饰/小标记（树、花、🔑…），s=1~3 占几格见方 {t:'path', kind:'road|dirt|river|fence|wall', pts:[[x,y],…]} // 一笔画出的线（路、河、围栏、城墙） ] } #}
