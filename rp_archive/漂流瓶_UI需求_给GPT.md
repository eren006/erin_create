## 提示词

你在帮我美化「长日小手机」里的**漂流瓶**功能的界面。这是一个跑在手机宽度（375px 为主）的网页手机，玩家扮演角色互相发匿名纸条，气质是 RP 恋综：克制、有留白、带一点诗意，不要做成花哨的游戏 UI。

### 先读这些
- `rp_archive/templates/phone.html`：一个文件靠 `mode` 变量分出所有页面。漂流瓶相关的三段是：
  - `{% elif mode == 'bottles' %}`：漂流瓶首页（扔瓶表单 + 我的漂流瓶列表）
  - `{% elif mode == 'bottle' %}`：单个瓶子的对话页（纸条往来 + 回信输入栏）
  - `{% elif mode == 'admin_bottles' %}`：管理员视角的瓶子总览（真名、只读）
  - 管理桌面上的图标已经有（`admin_app_icon('bottle')`），发现页里的入口行是 `🍾 漂流瓶`，可以一并换成统一风格的图标。
- 参考同文件里已经做得比较好的页面风格：点歌（`mode == 'song'`）、管理桌面（`admin-apps`）、催戏页（`admin_urge`）。
- 主题：`PHONE_THEMES` 有六套外观（现代/古风/科幻/中世纪/云絮邮局/民国），`skin.visual` 是当前外观名，颜色只用 CSS 变量（`--bg --line --mine --theirs --muted --text --gift-bg --gift-line`），**不要写死颜色**。浅色和深色模式都要好看。

### 要做的事
1. **漂流瓶首页（bottles）**
   - 顶部是「写一张纸条扔进海里」的区域：一个有仪式感的输入卡片（纸条/信笺的感觉），字数上限 `{{ max_msg }}`，按钮「扔出去」。`why` 非空时整个表单置灰并显示原因。
   - 下面是「我的漂流瓶」列表，每行是一个瓶子：瓶号 `#{{ t.id }}`、标签（`t.tag`：「我扔的」/「我捡到的」，可能为空）、最后一条内容预览、时间。
   - 列表里有三种状态要做出区别：**正常**（可点进去）、**发送中**（`t.state == 'pending'`，机器人还没处理，不可点，要有"漂在水上"的轻动效或脉冲）、**没扔出去**（`t.state == 'failed'`，显示 `t.note` 原因，不可点，偏警示色但别刺眼）。
   - 空状态（没有瓶子）要有一句好看的空白提示。
   - `has_pending` 为真时页面已有 8 秒自动刷新脚本，别删。
2. **单个瓶子（bottle）**
   - 顶部标题 `漂流瓶 #号` + 一行说明（「你扔出的 · 对方是捡到的人」/「你捡到的 · 抛瓶人匿名」/「抛瓶人匿名」）。**匿名是核心**：这里永远不会出现对方的真名，界面上不要暗示能查到对方是谁。
   - 纸条往来用气泡或信纸卡片都行，`m.mine` 区分自己和对方，`m.pending` 是还在等机器人处理的那条（时间文字是「发送中…」，要有区别）。
   - 底部回信输入栏（textarea + 发送），`why` 非空时禁用并把原因当占位提示。`failed` 非空时在顶部显示「上一条没有发出去：…」。
3. **管理员总览（admin_bottles）**：只读列表，每个瓶子一张卡：`#号  抛瓶人 → 捡瓶人`，下面是每条内容；`m.hidden` 的那条要标注「（对方看不到）」；`b.guess` 为真时显示「↔（方向未知）」。顶部有一句说明和 `pending` 数量。要比现在更清爽，但这是管理视角，信息密度可以高一点。
4. 发现页入口行和管理桌面图标的图标风格与整体统一（可以用内联 SVG，不引外部资源）。
