Ashfall — a cultivation RPG

An original text-based RPG built from scratch: character creation with four elemental paths, turn-based combat with per-path signature skills, a full cultivation/breakthrough leveling system, and a complete story arc from village to summit — playable start to finish in about ten minutes.

  • SQLite
  • Jinja2
  • Session-based persistence
  • Hand-written CSS

Flagship — a data product

Aperture — retail analytics dashboard

A live-queried BI dashboard, not a static chart dump: a synthetic year of retail order data in SQLite, real SQL aggregation on every request, and hand-built SVG charts — line, bar, stacked bar — with crosshair tooltips and date-range filters, no charting library.

  • Flask
  • SQLite
  • Real-time SQL aggregation
  • Hand-rolled SVG charts
  • No JS framework

Iceland Trip Planner

A mobile-friendly day-by-day itinerary for a real six-day Iceland road trip: interactive maps with turn-by-turn navigation links, a packing list that remembers what's checked, booking countdowns, and a searchable attraction guide. No database — content-driven entirely from Markdown.

  • Flask
  • Markdown
  • Leaflet / OpenStreetMap
  • localStorage
