玩法说明

这一页讲的数字都是从游戏里直接读出来的，游戏调整了这里也会跟着变。看不懂的地方，先看最后的「常见问题」。

先记住这几件事一天怎么过位分与圣宠银子人际与算计 有喜与子嗣夺嫡皇上换届家族常见问题

先记住这几件事

  • 一个账号就是一个家族，宫里同时只有一位小主。她没了，家里送下一位；每一届最多送 {{ FAMILY_MAX }} 位。
  • 一天是宫中半年。每晚 {{ '%02d:%02d' % (settle_h, settle_m) }} 统一结算：敬事房翻牌子、召见、生产、晋封、发例银、算计见分晓。你白天做的事，晚上一起见分晓。
  • 皇上会老。一届大约 55 天，之后皇上驾崩、开匾、新帝登基，宫里换一批人，你的家族接着来。
  • 精力每天 {{ ENERGY_MAX }} 点，用不完也不结转。每件事都做不完，也都不是非做不可。
  • 俸禄只够过日子。想升位、想使计、想养孩子，都得靠家里、生意和人情去挣。

一天怎么过

第一天

  • 注册后先「立家」：定姓氏（一次定下，不能改）和门第（8 种出身，决定属性加成、起始银子、殿选加分，还有你父亲的官职起点）。
  • 再填第一位小主的名、年龄、性格，分 12 点属性，参加殿选。殿选三问的答案和你的属性决定起始位分。
  • 入宫后去内务府挑宫人、赐名。许嬷嬷会带你走新人的几步，每步有小奖励。

每天早上

  • 昨夜宫中：先看敬事房昨晚递上去哪些牌子、皇上翻了谁；轮到你的话，会有一段侍寝或召见的小场景要你拿主意。
  • 口谕：皇上只在有值得说的事时才发口谕（晋封、生子、久未见驾……），没事不发。
  • 邸报是全宫的大事，书信是小主之间的私话，宫史和族谱记你一家人的来龙去脉。

  • 圣宠是皇上对你的喜欢，会自然流失（每晚约 {{ (FAVOR_DECAY * 100)|round|int }}%），怀孕时不流失。靠侍寝、召见、送汤羹、才艺涨。玩家最高到皇贵妃，皇后位由 NPC 占着。
  • 怎么被翻牌：每晚按权重抽签。圣宠、容貌、才艺都加分，会皇上当下喜好的那门才艺（修满 8 次算精通）大加分，新人头三天还有「喜新」加分，「送汤羹」能给当晚加权重。玩家每多 6 位，每晚多翻一位牌子。体质好、吃得好（奢华饮食）也有一点加分。
  • 召见是侍寝之外另外召的几位，久未见驾的人更容易被想起。
  • 信任是皇上信不信你：求情、告发、被人陷害时皇上信不信都看它。靠召见时说对话、侍疾涨，撒谎、求情失败会掉。
  • 禁足 {{ CONFINE_DAYS }} 天、冷宫 {{ COLD_DAYS }} 天是惩罚。冷宫里出不了门，日子难熬；期满会复位，但要从低位分重新爬。

银子

进项

  • 例银：按位分每晚发（见上表），这是最稳的，也最少。
  • 家里：家主官职高、名望够了，每 5 天托人送体己；写家书、投资生意都是赚钱的路。详见「家族」。
  • 皇子成年后孝敬、场景奖励、管理员的补偿信，零星的。

开销

  • 饮食（本宫页选）：每晚按位分扣，节俭 / 普通 / 奢华三档。
  • 宫人月钱每人每晚 {{ MAID_WAGE }} 两，发不出来宫人会寒心。
  • 修缮：屋子偶尔会坏（窗纸、漏雨、地龙、井水、梁柱），不修每晚伤身子。
  • 使计、买药、请太医、内务府买东西、送礼，都是大头。

礼佛

本宫页的「佛堂」：添香油钱（{% for a in PRAY_TIERS %}{{ a }}{{ '、' if not loop.last }}{% endfor %} 两）攒福报，福报高的人老死更慢、病重更有活路、更容易怀孕；这十天没对人使过计的「躺平」之人，还有机会延寿一年。

人际与算计

  • 好感：串门、写信、送礼涨，被算计会掉。好感够了可以结拜姐妹，姐妹能替你请太医、在你陷害时说话；一起长大的孩子也认这份交情。
  • 宫人是你的手脚：差遣去打探、收买、清查，也会遇到小事要你拿主意。忠心高才靠得住。
  • 秘密：每个人入宫前可能藏着一桩事（有意中人、冒认出身、私藏禁书……）。被人探到再告发，处罚比自己坦白重得多。
  • 雅趣（「暇趣」页）：莳花、调香、书画、茶事，起意→打磨→成了三步出一件作品，能摆进寝宫、能写信相赠。不给属性、不给圣宠，只留故事和人情。邀一两位小聚（清谈涨好感，探口风小概率带出一点不一定可信的暗示），对方不用同时在线，她当天上线就能看到、回应。隔上十几天会有一场节令小事（初雪、荷花开、七夕、重阳），那天做出的作品品级更容易高。
  • 人情：替人请过太医、她困顿时去看过她、送出过自己的第一件雅趣作品、在案子里替她作过证——这些事会被记住，小聚时对方可能会提起。

有喜与子嗣

  • 怎么怀：被翻牌那晚有机会，概率约 {{ (PREGNANCY_BASE * 100)|round|int }}% + 体质×0.2% + 福报×0.2%（体质 60 约 36%）；35 岁起打六折，45 岁起不再有孕。
  • 孕期{{ PREGNANCY_DAYS }} 天。本宫页有「有喜」卡：安胎静养降低难产风险，诵读诗书、听乐观射、礼佛积德让孩子出世时属性多一点底子。孕中当心，有人会下寒水散。
  • 生皇子母凭子贵（有名额时晋一级）。孩子有学问、骑射、品行、体质，还有性格。
  • 周岁抓周：贵人以下的生母，孩子要抱给嫔位以上的妃嫔养。周岁前你可以托付给相熟的姐妹，不然由皇上指人。你可以去探视，晋到嫔位再求皇上讨回。
  • 教养（本宫页，每个孩子每天一次）：读书、骑射、立规矩、陪他玩；还会遇到小事件要你拿主意；皇上每 7 天考校一个 6~15 岁的孩子。
  • 成年（16 岁）：皇子封爵开府，每晚孝敬银子，替母亲求情，每 3 天领一件差事要你选办法；公主指婚，留京下嫁或抚蒙古（圣眷和信任够了才能自己选）。
  • 时间尺度是一天半年：孩子出生后满 24 天才到 12 岁，能入夺嫡；第 30 天以后才出生的孩子，多半赶不上这一届。

夺嫡

  • 圣眷（阿哥的）= 学问×0.3 + 骑射×0.2 + 品行×0.3 + 累计功绩 + 抚养人位分加成 + 抚养人信任×0.1 + 家族的助力。12 岁以上的阿哥都算储位人选。
  • 站队：明着站（邸报公开、他的党羽 +1）或暗里站（只悄悄塞银子），7 天内不能改。党羽超过 5 个皇上忌惮，超过 8 个当众训斥。
  • 朝议立储每 10 天一次，圣眷最高 ≥ 70 且领先第二名 15 以上才明立太子；太子圣眷掉到 50 以下会被废。万寿节每 20 天，阿哥们献寿礼比高下。
  • 手段（夺嫡页）：离间、收买上书房、公主进言、挑拨兄弟、构陷皇子（妃位以上，查实就圈禁出局、抚养人降一级，没坐实也可能被查出是谁在使坏），都不能直接害死皇嗣，只能在圣眷或储位资格上做文章。
  • 开匾：皇上驾崩那晚，匾后是谁按圣眷的平方抽签，圣眷高的胜面大，弱的也有机会。窥匾能探到眼下胜面；矫诏（贵妃以上、只在病重的三天里、一辈子一次）成功就是必中，败露赐死。
  • 新帝登基：生母、养母里在世的、跟他情分高的成圣母皇太后，另一位太妃；明站他的人按支持天数封太妃；押错了阿哥的失势。

皇上换届

  • 皇上开局 45 岁，一天长半岁；60 岁起每晚有驾崩的可能，最晚第 70 天必驾崩。
  • 驾崩前有 3 天病重：不翻牌子、不召见，可以去养心殿侍疾（成了信任 +5）。这是夺嫡最后的几天。
  • 驾崩那晚定下遗诏，历代页记下这一届的新帝、太后、每个人的结局和几项纪录。国丧一天，第二天开下一届选秀。
  • 下一届的皇上就是新登基的那位阿哥，脾气学问带过去（学问高偏爱才艺、骑射高偏爱体质好的……）；NPC 妃嫔换一批；你的账号、家族、宫史、族谱都在，角色、银子、关系、孩子重来。

家族

  • 家主（先是父亲，没了是兄长、侄子）有年龄、官职，会老、会病、会升迁降职。官职越高，家里越发达：会定期送钱，夺嫡时是你家阿哥的助力。
  • 名望跨届累积：成员晋位、生皇子、出太后、寿终涨；打入冷宫、秘密被告发会掉。名望高的家族，新成员殿选加分、起始银子多，也更不容易被御史参。
  • 家里来信（每 4 天左右一封，5 天内回信）：升迁要打点银子、闯了祸要你说情、欠债、家主病了、夺嫡该站哪位阿哥。不回也有代价。
  • 联络家里（顶部「家族」）：送银子回家（记进家底，下一辈也能取）、支取家底、写家书、替家主荐官、表态支持哪位阿哥。
  • 家里的生意：本金 50~{{ VENTURE_MAX }} 两投出去，几天后结账，有赚有亏，最险的还会招来御史。

常见问题

为什么总不被翻牌？

翻牌是抽签，全宫每晚才翻一两位。想提高机会：多送汤羹、练好皇上当下喜欢的才艺、保养容貌、吃得好一点（奢华饮食）。被召见比被翻牌容易，去养心殿转转也有用。

银子总不够怎么办？

去「家族」页看看：回家里的信、投一笔绸缎庄（最稳）、写家书。家主官职高了，家里会定期送钱。日常别每样都做满，梳妆和送汤羹是最花钱的。饮食降一档也能省。

被人害了怎么办？

中毒或病重立刻请太医（自己或姐妹替你请）；有眼线能知道是谁；案子开了去慎刑司陈情。别急着报复，先保命。

怀不上孩子？

体质、福报、饮食都有影响；被翻牌次数本身也是关键。礼佛攒福报、静养保体质。孩子太晚出生赶不上这一届也没关系，下一届是新的一轮。

我的小主死了怎么办？

去宫史页，家里治丧两天后点「家里再送一位入宫」。这一届最多送 {{ FAMILY_MAX }} 位，都没了就等下一届。

换届之后我什么都没了吗？

角色、银子、孩子、关系没了，但家族、名望、家底、族谱、你留下的信都在，新成员还能带嫁妆、认姑母。

有问题、发现 bug、觉得哪里不对，用页脚的「投诉举报」或者直接联系管理员。
