# 排单宝项目约定

## 所有主题的图片素材

- 用户要求：今后所有主题素材都必须先压缩，再接入网页和部署，不能把生成原图直接作为线上资源。
- 根据实际展示尺寸缩放，通常保留约 2 倍显示分辨率；优先使用 WebP，透明素材必须保留 alpha 边缘。SVG 等矢量素材按需优化，不必转成位图。
- 压缩后检查桌面和手机上的清晰度、透明边缘、裁切及动效；记录压缩前后的大小。
- 新增主题、主题头图、装饰及替换素材均遵守此规则。生成原稿作为备份，不随日常部署重复上传。
- 优先复用 `work/compress_ballet_assets.py` 的压缩方式，按新素材扩展配置；网页与部署清单必须引用压缩版。
