# 末日基地2.0 系统评估（v1.6）

## 总结

当前版本已经不是“功能少”，而是中层循环太多、共同结算轴太少。主线、探索和制造本来能成立，但生活、关系和沉浸内容过去主要提供文本，玩家会觉得“看过了，却没有影响我的一天”。v1.6 用娱乐/精神状态把做饭、饮品、广播、NPC、房间、相册、家庭、动物和钓鱼接回生存循环，同时修复任务不可主动完成及部分资源无出口的问题。

## 主线评估

- 八章北辰主线按顺序解锁，最早幸存第8天通关；漏做不会过期，符合“至少8天，但可以更久”。
- 章节门槛全部使用角色个人累计数据，不依赖其他玩家。第1—6章覆盖移动、采集、留言、运气；第7—8章覆盖战斗。
- 原缺陷：后两章战斗只能随机遇敌，目标明确但执行入口不明确。
- v1.6：第7—8章加入“追踪北辰守门尸群”，玩家可以主动开战，也可以撤退整备。主线仍有风险，但不再等随机数。
- 八章选择会进入档案与最终广播，负责角色扮演表达，不设置“选错即坏结局”，避免攻略压力。
- 北辰个人行动每日一次仍是时间门槛；章节目标未完成会保留，因此真正通关时间取决于行动，而不是到第8天自动放行。

结论：主线可独立通关、时间门槛清楚、后段现在可主动推进。后续若扩章，应优先增加“章节专属场景/敌人”，而不是继续提高累计采集量。

## 任务系统评估

### 每日目标

旧池包含战斗、制作、捐献，可能在新手没有敌人、图纸或庇护所时抽到，属于不可控目标。v1.6 改为移动、采集、北辰行动、废土手气、主动休息五类，随机抽三项；全部可以单人主动完成，不完成无惩罚。

### 固定支线

支线覆盖探索、制作、社区、钓鱼、无线电、委托与救援，能引导玩家尝试不同系统。原缺陷是社交/后期支线可能长期占满三个槽。v1.6 允许每天无奖励换掉一条，既保留引导，也不逼玩家等待别人。

### 动态支线

远征受伤、庇护所事件会留下后续任务，因果关系成立。v1.6 又让NPC信任达到7时生成私人委托，达到15时留下可信呼号、相册记录和奖励，使“信任数字”不再只是展示。

## 资源与功能闭环

已确认的主要链条：

- 地图采集 → 建房/工作台 → 图纸制作 → 装备、钓鱼、雷达与医疗。
- 钓鱼 → 处理鱼肉 → 菜谱 → 饥饿与娱乐。
- 农田/远征 → 蔬菜、谷物、水果 → 做饭与酿造 → 生存与娱乐。
- 畜牧 → 蛋、奶、兔毛 → 菜谱与服装；投喂同时少量恢复娱乐。
- 狩猎陷阱 → 兽皮 → 保暖/家族服装（v1.6补上兽皮出口）。
- 枪战 → 弹壳/火药 → 弹药复装 → 枪械消耗（v1.6补上枪械实际耗弹）。
- 废墟拆解 → 金属/零件/电器/枪油 → 生存工坊、武器保养与弹药线。
- 生水 → 污染检测 → 对应处理材料 → 净水。
- 银料/宝石/共鸣材料 → 戒指 → 婚姻与家族。
- 家庭/远征/成长 → 相册与遗物 → 传承；相册现在也可作为休息方式。
- 玩家行动 → 日目标/支线/主线计数 → 钱包、经验、图纸点 → 商人、畜牧、制造。

v1.6同时修正废墟拆解的任务进度：现在按真实拆出数量计入采集，不再另外随机一个无关数字。

## 娱乐与精神状态

- 初始娱乐70，上限100，每个角色幸存日自然下降6。
- 30以上不影响效率；15—29提示紧绷；低于15时采集/战斗效率仅额外降低10%，避免滚雪球。
- 低于15后每天有18%崩溃概率，娱乐为0时为30%。可能发生茫然、失控进食、损坏武器、游荡受伤或惊恐受伤。
- 普通离线崩溃与饥饿最多把角色压到1HP，不会让玩家因为没上线直接死亡。只有娱乐为0、已经重伤、角色最近仍在主动行动时，惊恐事故才有极低概率致命。
- 每天可以主动休息一次，但不是唯一恢复手段。热饭、饮品、钓鱼、NPC联络、睡前广播、庇护所生活事件和照顾动物都会自然恢复娱乐。

这使娱乐成为“选择怎样活”的反馈，不是第四条必须打卡的饥饿槽。

## 压力评估

旧生存消耗每游戏小时扣4点，一游戏日会扣96点，实际要求玩家在一小时现实时间内多次进食。v1.6校正为每游戏小时约1点、一游戏日约24点，并加入tick小数余数累计。一份普通食物和水可以大致维持一天，离线结算不直接饿死。

仍保留的压力来源是主动远行、战斗、感染、天气、废墟噪声和低娱乐时继续冒险。它们都有预警、整备或撤退空间，属于玩家选择的风险。

## 仍可继续优化

- 庇护所1000份共鸣材料的旧终局是全服长期工程，不应替代个人北辰通关；界面需要始终把两者标成“个人结局”和“世界工程”。
- 生活工坊前期建设链较长，可观察真实玩家数据后再决定是否赠送首个厨房设施，不建议现在直接降价。
- 世界目标给所有活人奖励，参与感宽松但存在搭便车；当前优先降低压力，暂不改为贡献排名。
- 系统已经很多。下一阶段应优先增加事件文本、专属敌人和任务变体，少加新的独立数值条。
