语擦助手图片服务 - 使用说明
================================

这是什么：
配合海豹骰子插件「语擦助手」用的图片渲染服务，负责生成「月历图」「结局分布图」
「年度总览图」这三个指令用到的图片。没有它，这些指令会自动变成发文字，其它指令不受影响。

这个服务要装在【跑海豹骰子的那台 Windows 服务器】上（图片服务只监听 127.0.0.1，
必须和海豹同一台机器才连得上）。你自己操作用的电脑（不管是 Windows 还是 Mac）
只是用来"遥控"部署，两种方法效果完全一样，挑你自己在用的系统对应的那个就行。

------------------------------------------------------------
开始之前：确保服务器的 22 端口是打开的
------------------------------------------------------------

部署工具走的是 SSH（22 端口），不是远程桌面（3389）——这是两个完全不同的东西，
装了远程桌面不代表 SSH 也能用。如果没连过 SSH，大概率这一步还没做，先花两分钟
检查，不然点了"开始部署"只会一直报"连不上"。要检查两层，两层都要打开：

【第一层：云服务商控制台的防火墙/安全组】
这是"外网能不能碰到这台服务器的 22 端口"这一关，跟服务器里装了什么没关系。
不管用的是哪家云，思路都一样：去控制台找到这台服务器的防火墙/安全组设置，
加一条"放行 TCP 22"的入站规则。下面是两家最常见的具体操作（其它云商基本是
同一套逻辑，去控制台里找"防火墙"或"安全组"就行）：

腾讯云"轻量应用服务器"：
   1. 登录腾讯云控制台，进这台服务器的详情页
   2. 点"防火墙"标签页，点"添加规则"
   3. 应用类型选"Linux 登录 (22)"——虽然写着 Linux，但本质就是"TCP 22 端口"这
      一条规则，跟服务器是不是 Windows 没关系，选它会自动帮你填好协议和端口，
      不用手填
   4. 来源选"全部IPv4地址"（图省事、先测通；更严谨的话可以只填你自己会用到
      的固定公网 IP，但公网 IP 经常会变，不确定就先用全部）
   5. 策略选"允许"，保存
   这是"新增一条规则"，不会动到这台服务器已有的其它规则（比如 3389）。
   ⚠️ 如果你在防火墙页面看到的是"防火墙模板"这个功能（用于批量给多台服务器
   设置规则），要特别小心：应用模板是整体替换而不是新增，会把这台服务器原有
   的所有规则（包括 3389）全部覆盖掉。除非你确定要批量管理多台服务器，否则
   走上面"实例详情页 -> 防火墙 -> 添加规则"这条路更安全。

阿里云"轻量应用服务器"：
   1. 登录阿里云控制台，进"轻量应用服务器" -> 找到这台服务器，点实例 ID 进详情页
   2. 点"防火墙"标签页，点"添加规则"
   3. 应用类型直接选"SSH"这个预设选项，协议（TCP）和端口范围（22）会自动
      填好，不用手填
   4. 来源选"全部IPv4地址"（0.0.0.0/0），或者按需填你自己的固定公网 IP
   5. 备注可填可不填，保存
   这条规则只在"端口+协议+来源 IP 都跟已有规则完全重复"时才会覆盖那一条重复
   的规则，不会影响其它不相关的规则（比如 3389），新增一条 22 端口规则是安全
   的，不用担心把已有配置搞没。

【第二层：服务器系统自己（装了 SSH 服务、系统防火墙放行）】
云端规则放行了，不代表服务器里真的有东西在监听 22 端口。Windows 默认不带
SSH 服务，得自己装。如果你能通过远程桌面/VNC 进到这台服务器桌面，用**管理员
身份**打开 PowerShell，把这个文件夹里「open_ssh_port.ps1」的内容整段复制进去
回车运行（检查/安装 OpenSSH Server、设成开机自启、补一条系统防火墙放行规则，
最后打印验证结果；重复运行也没关系，不会重复安装/报错）。

   跑完看最后的验证输出：Status 应该是 Running、StartType 是 Automatic、
   netstat 那行应该能看到 0.0.0.0:22 LISTENING、防火墙规则应该是 Enabled=True
   /Action=Allow。全部对上就是这一层没问题了。

【怎么判断具体是哪一层没打开】两层都打开之后再部署，如果还是连不上，看
黑窗口里报错的具体措辞能帮你缩小范围：
   - `Connection timed out`（超时无响应）：包根本没到服务器，通常是第一层
     （云端防火墙/安全组）没放行
   - `Connection refused`（连接被拒绝）：包已经到了服务器，是服务器自己拒绝
     的，通常是第二层（sshd 没装/没启动，或者系统防火墙挡住了）

------------------------------------------------------------
方法一：用 Windows 电脑部署 —— 双击 deploy_windows.bat
------------------------------------------------------------

1. 双击「deploy_windows.bat」，弹出一个小窗口，依次填：
   - 服务器地址：跑海豹的那台服务器的公网 IP 或域名，不要带端口号
   - SSH 用户名：登录那台服务器用的账号名（一般和远程桌面登录同一个）
   - SSH 端口：不确定就留默认 22
   - SSH 密码：填了的话部署过程全自动，不用再手动输入；留空的话就退回成
     手动输入（下一步的黑窗口里会问你要）
   - 服务器上放到哪个路径：默认 C:\yuca_image_server 就行，路径里不要带空格
2. 点"开始部署"，会弹出一个黑色命令行窗口，接下来检测/安装 Node.js、连接、
   传文件、装依赖、启动服务全在这个窗口里跑。第一次连接某台服务器时还会问
   一次要不要信任它的指纹，这个问题跳不过去（安全机制），照着输入 y 或者
   yes 就行；如果你填了密码，除了这一次指纹确认，其它步骤全自动，不用再
   手动输入密码。
   （首次使用会自动下载 plink.exe/pscp.exe 到这个文件夹里，用来实现自动
   输密码，来自 PuTTY 官方镜像，需要联网。）
3. 看到"部署完成"就成功了。

【案例】要部署到 IP 为 120.26.120.128、账号 Administrator 的服务器：
   服务器地址：120.26.120.128
   SSH 用户名：Administrator
   SSH 端口：22（默认）
   SSH 密码：这台服务器的开机/远程桌面密码
   服务器路径：C:\yuca_image_server（默认）

【关于密码】填在这里的密码只会通过环境变量传给本机的 plink/pscp 用于这一次
部署，不会写进任何文件；部署这台电脑上如果有别的程序在这几秒钟内查看正在
运行的进程命令行（比如任务管理器的"命令行"列），理论上能看到明文密码——
这是 plink/pscp 本身的限制，没法完全避免。不放心的话密码栏留空，退回手动
输入的方式。

------------------------------------------------------------
方法二：用 Mac 电脑部署 —— 双击 deploy_mac.command
------------------------------------------------------------

前提：这台 Mac 上要先装了 expect（用来在弹窗里自动把密码传给 ssh）。没装的话
双击后会提示，打开"终端"敲一行装上就行：
   brew install expect
装完重新双击 deploy_mac.command。

1. 双击「deploy_mac.command」（如果系统提示"无法打开，因为来自身份不明的开发者"，
   在"访达"里右键这个文件选"打开"，再点一次弹窗里的"打开"就行，这个警告只在
   第一次出现）。
2. 会自动打开终端窗口，并依次弹出几个小对话框，跟 Windows 版填的是同一批信息：
   - 服务器地址（只填 IP/域名，不带端口号）
   - SSH 用户名
   - SSH 端口（默认 22）
   - 服务器上的目标路径（默认 C:/yuca_image_server）
   - SSH 密码（这一步会隐藏输入）
3. 填完最后一项后，终端窗口里会自动跑完连接、传文件、装依赖、启动服务的全过程。
4. 看到"部署完成"就成功了。

【案例】同样部署到 120.26.120.128：
   服务器地址：120.26.120.128
   SSH 用户名：Administrator
   SSH 端口：22
   服务器路径：C:/yuca_image_server
   SSH 密码：这台服务器的开机/远程桌面密码

------------------------------------------------------------
两种方法的共同点
------------------------------------------------------------

- 都是"远程操作"：你双击的那个文件是在你自己电脑上跑的，真正跑图片服务的是
  你填的那台远程服务器，不是你自己这台电脑。
- Node.js 不用提前装，工具会自动检测，没有的话自动下载官方 LTS 版静默安装
  （需要服务器能联网）。
- 服务注册成 Windows 计划任务启动（开机自启），不是普通窗口，服务器重启后
  会自动恢复，不用你手动去重开。
- 都可以重复运行——如果服务器上已经装过了，重新跑一遍就是"更新"：文件会
  覆盖成最新版，旧进程自动结束，再用新代码重新启动，不用手动去服务器上
  清理什么。

------------------------------------------------------------
最后一步：海豹那边加载插件（两种方法都要做）
------------------------------------------------------------

另外应该还收到了一个「语擦助手_合并版.js」文件，这个不是图片服务的一部分，
是海豹骰子的插件本体。把它放进海豹的 JS 插件目录，在海豹后台正常加载/启用
就行，跟装其它海豹插件的方式一样。

装完这两样，「录入档期」「月历图」「结局分布图」「年度总览图」这些指令就
都能用了。

------------------------------------------------------------
遇到问题
------------------------------------------------------------

黑色窗口/终端窗口里报错了，把报错的文字截图/复制下来发回来问就行。
图片指令如果报"图片服务未启动"之类的提示，现在会直接把具体原因显示在群消息
里（比如"图片服务无响应"就是服务器上没有服务在跑，重新用上面任一方法部署
一遍就行）。
